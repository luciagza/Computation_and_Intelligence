Sesión de laboratorio 6: Sistemas de Recomendación

Objetivos de la sesión

🎯 Objetivo General: Entender las ideas fundamentales detrás de los sistemas de recomendación y aprender a diseñar, implementar y evaluar modelos de recomendación sencillos usando Orange. Explorarás diferentes enfoques — basados en popularidad, basados en contenido y filtrado colaborativo — y compararás sus ventajas y limitaciones.

Los sistemas de recomendación son los motores invisibles que personalizan nuestras experiencias digitales. Guían lo que vemos en Netflix, lo que compramos en Amazon y lo que leemos en Goodreads. Al aprender las preferencias de los usuarios y las relaciones entre ítems, estos sistemas predicen qué elementos son más relevantes para cada usuario, aumentando tanto la satisfacción como el engagement.

En este laboratorio vas a:

  • Explorar los datos usados para entrenar sistemas de recomendación.
  • Implementar y evaluar tres estrategias principales de recomendación:
    1. Modelos basados en popularidad, que sugieren lo que es generalmente popular.
    2. Filtrado basado en contenido, que encuentra ítems similares a los que un usuario ya prefiere.
    3. Filtrado colaborativo, que se basa en la sabiduría de usuarios similares.

Antes de comenzar, asegúrate de tener el entorno de Orange preparado. El complemento orange3-recommendation extiende Orange con herramientas específicas para construir sistemas de recomendación:

conda activate orange3
pip install orange3-recommendation

2. Recomendación basada en popularidad

🎯 Objetivo: Implementar un sistema de recomendación basado en la popularidad y evaluar su rendimiento.

En esta sección, implementaremos una forma simple de recomendar libros basada en las calificaciones. Calcularemos cuál es el libro más probable que le gustaría a un usuario en función de las calificaciones de otros usuarios. Específicamente, calcularemos la calificación media de cada libro y recomendaremos los libros con las calificaciones medias más altas.

Ten en cuenta que un recomendador basado en popularidad ignora las preferencias individuales de los usuarios. En lugar de eso, asume que los ítems que gustan a muchos usuarios son más propensos a gustarle a un nuevo usuario.

Para hacer esto, utilizaremos el widget Baselines en Orange. Pasa los datos de entrenamiento y configúralo para calcular el promedio de usuario como la estrategia de recomendación. Luego, conecta la salida a un widget Predictions para evaluar su rendimiento con los datos de prueba.

Repite el proceso utilizando la calificación media de cada libro como la estrategia de recomendación. Compara los resultados de ambos enfoques.

  2. ¿Cómo afecta la elección de la estrategia de recomendación (promedio de usuario vs. promedio de ítem) al rendimiento del sistema?
  3. ¿Cuáles son las limitaciones de los sistemas de recomendación basados en la popularidad?

3. Filtrado basado en contenido

🎯 Objetivo: Implementar un sistema de recomendación basado en contenido y evaluar su rendimiento.

En esta sección, implementaremos un sistema de recomendación basado en contenido. Este enfoque recomienda elementos en función de la similitud entre ellos. Utilizaremos las características de los libros (por ejemplo, género, autor, etc.) para calcular la similitud entre libros. Para hacer esto, consideraremos un escenario en el que el usuario nos dice qué libro le gusta y recomendaremos libros similares en función de esa información.

Para implementar esto, utilizaremos las características de los libros, disponibles aquí, y las cargaremos en Orange utilizando el widget File. Luego, utilizaremos el widget Distance para calcular la similitud entre libros en función de sus características. Puedes visualizar la matriz de similitud utilizando el widget Distance matrix.

A continuación, utilizaremos el widget Python Script para crear una función de recomendación personalizada que tome un libro y recomiende libros similares en función de la matriz de similitud. Para ello, tendremos que pasar como entrada al modelo la matriz de similitud y los datos de todos los libros que hemos cargado con el widget File. El código en Python puede ser el siguiente:

import numpy as np

# --- Choose the book you want to query ---
book_title = "Harry Potter and the Goblet of Fire (Book 4)"   # You can change this to any book in the dataset

# --- Inputs from Orange ---
data = in_data               # Orange Table
dist = np.array(in_object)   # DistMatrix as NumPy array

# Extract book titles from metas (adjust the field name if needed)
book_names = [str(inst["title"]) if "title" in data.domain else str(inst.metas[0]) for inst in data]

# Try to find the index of the chosen book
try:
    idx = book_names.index(book_title)
except ValueError:
    print(f"❌ Book '{book_title}' not found!")
    idx = None

if idx is not None:
    # Get distances from this book to all others
    distances = dist[idx]

    # Find the 5 nearest (excluding itself)
    nearest_idx = np.argsort(distances)[1:6]

    print(f"\n📚 5 most similar to '{book_title}':\n")
    for i in nearest_idx:
        print(f"  {book_names[i]}  (distance = {distances[i]:.3f})")

Prueba la función con diferentes libros y observa las recomendaciones generadas.

4. Filtrado colaborativo

🎯 Objetivo: Implementar un sistema de recomendación basado en filtrado colaborativo y evaluar su rendimiento.

Finalmente, implementaremos un sistema de recomendación basado en filtrado colaborativo. Este enfoque recomienda elementos en función de las preferencias de usuarios similares. Utilizaremos las calificaciones dadas por los usuarios para encontrar usuarios similares y recomendar libros que esos usuarios hayan disfrutado.

Aquí nos centraremos en un tipo de filtrado colaborativo llamado factorización de matrices. Este método descompone la matriz de interacción usuario-elemento en dos matrices de menor dimensión, una que representa a los usuarios y otra que representa a los elementos. El producto punto de estas matrices se puede utilizar para predecir calificaciones faltantes: \[ R \approx P \cdot Q^T, \] donde (R) es la matriz de interacción original usuario-elemento, (P) es la matriz de características del usuario y (Q) es la matriz de características del elemento.

Para implementar esto, utilizaremos el widget BRISMF en Orange. Pasa los datos de entrenamiento al widget y configura sus parámetros (por ejemplo, número de factores, regularización). Luego, conecta la salida a un widget de Predictions para evaluar su rendimiento con los datos de prueba.

También podemos visualizar las características latentes aprendidas por el modelo utilizando la representación de baja dimensión de usuarios y elementos. Utiliza el widget t-SNE para reducir la dimensionalidad de la matriz de características del elemento (matriz (Q)) y visualizarla.

5. Recomendación usando Surprise

🎯 Objetivo: Implementar un sistema de recomendación usando la biblioteca Surprise y evaluar su rendimiento.

En esta sección, implementaremos un sistema de recomendación usando la biblioteca Surprise, que es un scikit de Python para construir y analizar sistemas de recomendación. Surprise proporciona varios algoritmos para filtrado colaborativo, incluidas técnicas de factorización de matrices como SVD.

Para usar Surprise dentro de Orange, podemos utilizar el widget Python Script. A continuación se muestra un código de ejemplo que demuestra cómo usar Surprise para construir un modelo de recomendación utilizando el algoritmo SVD. Este código asume que los datos de entrada han sido preprocesados y contienen las columnas necesarias: userID, bookID y rating.

# --- Imports ---
import pandas as pd
from surprise import Reader, Dataset, SVD
from surprise.model_selection import cross_validate

# --- Extract data from Orange input ---
# in_data is an Orange Table object automatically provided by Orange
# We need to convert it to a pandas DataFrame
df = pd.DataFrame(in_data.X, columns=[var.name for var in in_data.domain.attributes])

# If the target variable (rating) is in Y:
if in_data.domain.has_continuous_class or in_data.domain.has_discrete_class:
    df["rating"] = in_data.Y

# If userID and bookID are stored as metas:
for i, var in enumerate(in_data.domain.metas):
    df[var.name] = [str(val) for val in in_data.metas[:, i]]

# --- Inspect your dataframe ---
print(df.head())

# Make sure it has columns: userID, bookID, rating
# If not, rename accordingly
df = df.rename(columns={
    "userID": "userID",
    "bookID": "bookID",
    "rating": "bookRating"
})

# --- Prepare the Surprise dataset ---
reader = Reader(rating_scale=(1, 10))
data = Dataset.load_from_df(df[["userID", "bookID", "bookRating"]], reader)

# --- Train a simple model using SVD ---
algo = SVD()

# Evaluate with 3-fold cross-validation
results = cross_validate(algo, data, measures=['RMSE', 'MAE'], cv=5, verbose=True)

print("\n✅ Cross-validation results:")
for key, value in results.items():
    print(f"{key}: {value}")

Puedes modificar el código para experimentar con diferentes algoritmos proporcionados por Surprise, como KNNBasic, NMF, etc. Además, puedes ajustar los hiperparámetros para mejorar el rendimiento del modelo.
